# CardNote

Nativní aplikace pro Android v Kotlinu a Jetpack Compose. Karty budou později sestavitelné z jednotlivých bloků, upravitelné přímo na obrazovce a použitelné offline bez SQL.

První milník: vzhledová verze karet podle původní ukázky se statickým obsahem. Následují přímé úpravy, přesouvání, ukládání a zálohy.

Zdrojový kód a sestavení Android aplikace doplníme v dalších commitech.
